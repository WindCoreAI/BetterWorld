# Dashboard Flow

> Generated by /ux-flows on 2026-02-17

## Setup Requirements

- [ ] API server running (port 4000)
- [ ] Web server running (port 3000)
- [ ] PostgreSQL with betterworld database
- [ ] Redis running
- [ ] Registered and verified human with completed onboarding
- [ ] Human should have some activity (missions, tokens, reputation) for full dashboard display

## Test Scenarios

### Scenario 1: Main Dashboard Loads All Cards

**Pages**: /dashboard
**Auth Required**: Yes (redirects to /auth/human/login if unauthenticated; redirects to /onboarding if not completed)
**Prerequisites**: Authenticated human with completed orientation

**Steps**:
1. Authenticate in browser via `authenticateInBrowser`
2. Navigate to `/dashboard`
3. Verify heading "Welcome back, {displayName}" is visible
4. Verify reputation score and streak row renders
5. Verify TokenBalanceCard renders with balance info
6. Verify ProfileCompletenessCard renders with score
7. Verify MissionsCard renders (active missions or empty state)
8. Verify RecentActivityCard renders
9. Verify EvidenceStatusCard renders
10. Verify PeerReviewsCard renders
11. Verify YourNetworkCard renders (followers/connections counts)
12. Verify ImpactRippleCard renders
13. Verify MyAgentsCard renders (agent count or CTA)
14. Verify no console errors

**Expected Outcomes**:
- Dashboard page fully loads with all card components
- GET /api/v1/dashboard returns user data, token balance, missions, activity
- Reputation score and tier badge displayed
- Streak counter and multiplier shown
- All cards render without errors

**API Calls Involved**:
- GET /api/v1/dashboard -> { ok: true, data: { human: {...}, tokens: { balance, totalEarned, totalSpent }, missions: [...], activity: [...] } }
- GET /api/v1/profile -> { ok: true, data: { profile, completenessScore } }
- GET /api/v1/reputation/:id -> { ok: true, data: { reputation } }
- GET /api/v1/streaks/me -> { ok: true, data: { streak } }
- GET /api/v1/notifications/unread-count -> { ok: true, data: { unreadCount } }
- GET /api/v1/my-agents -> { ok: true, data: { agents: [...] } }

**Selectors**:
- Welcome heading: `text=Welcome back`
- Token card: TokenBalanceCard component
- Profile card: ProfileCompletenessCard component
- Missions card: MissionsCard component
- Activity card: RecentActivityCard component
- Evidence card: EvidenceStatusCard component
- Reviews card: PeerReviewsCard component
- Network card: YourNetworkCard component
- Ripple card: ImpactRippleCard component
- Agents card: MyAgentsCard component
- Reputation score: ReputationScore component
- Tier badge: TierBadge component
- Streak: StreakCounter component

### Scenario 6: Feedback Inbox

**Pages**: /dashboard/feedback
**Auth Required**: Yes (implicit, uses authenticated API)
**Prerequisites**: Authenticated human (preferably with some feedback entries)

**Steps**:
1. Authenticate in browser
2. Navigate to `/dashboard/feedback`
3. Verify heading "Feedback Inbox" is visible
4. Verify unread count badge
5. Verify "Unread only" checkbox filter
6. Verify feedback list renders (FeedbackList component)
7. Toggle "Unread only" checkbox
8. Verify list filters to unread items only
9. Click on a feedback item
10. Verify it gets marked as read

**Expected Outcomes**:
- Feedback inbox loads with items sorted by date
- Unread count badge shows accurate count
- "Unread only" filter works
- Mark-as-read updates the unread count

**API Calls Involved**:
- GET /api/v1/feedback -> { ok: true, data: { feedback: [...], cursor } }
- GET /api/v1/feedback/unread-count -> { ok: true, data: { unreadCount } }
- PATCH /api/v1/feedback/:id/read -> { ok: true }

**Selectors**:
- Heading: `text=Feedback Inbox`
- Unread badge: Count indicator
- Unread filter: Checkbox labeled "Unread only"
- Feedback list: FeedbackList component
- Feedback items: Individual feedback entries (evidence_rejection, review_disagreement, high_performer_recognition)
