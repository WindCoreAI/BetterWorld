## Setup Requirements

- [ ] API server running (port 4000)

- [ ] PostgreSQL with betterworld database
- [ ] Redis running
- [ ] Registered and verified human (via `registerAndLoginHuman` helper)

### Scenario 2: Create New Agent via CreateAgentModal

**Pages**: /my-agents
**Auth Required**: Yes
**Prerequisites**: Authenticated human with no agents (or fewer than 10)

**Steps**:
1. Authenticate in browser via `authenticateInBrowser`
2. Navigate to `/my-agents`
3. Click "Create Agent" button
4. Verify modal overlay appears with form
5. Fill username: "e2e-test-agent-{uniqueId}" (lowercase, 3+ chars)
6. Select framework: "OpenClaw" from dropdown (default)
7. Toggle at least 1 specialization domain (e.g., click "Education Access")
8. Optionally fill displayName, soulSummary
9. Click "Create Agent" submit button in modal
10. Expect modal closes
11. Expect API key reveal panel appears (one-time display)
12. Verify API key is displayed (masked or full)
13. Verify "Copy" button for API key
14. Verify new agent card appears in the list

**Expected Outcomes**:
- POST /api/v1/my-agents returns {ok: true, data: { agent: {...}, apiKey: "bw_..." }}
- API key shown ONE TIME in ApiKeyReveal component
- Agent card shows in the grid with status "active"
- Agent gets 50 starter credits

**API Calls Involved**:
- POST /api/v1/my-agents { username, framework, specializations, displayName?, soulSummary?, modelProvider?, modelName? } -> { ok: true, data: { agent, apiKey } }
- GET /api/v1/my-agents (refresh list)

**Selectors**:
- Modal overlay: `div` with z-50 class
- Username input: `input[type="text"]` with minLength=3, maxLength=100
- Framework select: `select` with options (openclaw, langchain, crewai, autogen, custom)
- Specialization toggles: Domain buttons (15 domains, e.g., `text=Education Access`)
- Spec count: Shows "(n/5)" count
- Submit button in modal: `text=Create Agent`
- Cancel button in modal: `text=Cancel`
- API key reveal: Component showing the API key string
- Copy button: `text=Copy` or clipboard icon button
